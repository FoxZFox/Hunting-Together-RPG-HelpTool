# RoomSpoof — Hunting Together RPG

Chrome extension สำหรับเลือกห้อง (server) ของแมพ
[Hunting Together RPG](https://www.roblox.com/games/117483759937632/Hunting-Together-RPG)
โดยดึงห้องที่ ping ต่ำ / คนน้อย มาให้ แล้วกด Auto Join ได้ทันที
ห้องที่เคยเข้าผ่าน extension จะติดคูลดาวน์ (ค่าเริ่มต้น 15 นาที) จะไม่ถูกเลือกซ้ำจนกว่าจะหมดเวลา

แผงควบคุมจะแสดง **เฉพาะในหน้าเกมนี้เท่านั้น** หน้าอื่นของ Roblox จะไม่มีอะไรขึ้น และไอคอน extension จะเป็นสีเทา

## สิ่งที่ต้องมี (Requirements)

| ต้องมี | รายละเอียด |
| --- | --- |
| Google Chrome (หรือเบราว์เซอร์ตระกูล Chromium ที่ลงส่วนเสริมแบบ unpacked ได้ เช่น Edge) | ส่วนเสริมนี้เป็น Manifest V3 ใช้สิทธิ์แค่ `storage` กับ `declarativeContent` |
| ล็อกอิน roblox.com ในเบราว์เซอร์นั้น | ใช้ปุ่มเข้าเกมของหน้าเว็บ Roblox |
| Roblox Player ติดตั้งบน PC | ตอนกดเข้าห้อง เบราว์เซอร์จะเปิด Roblox ผ่านลิงก์ `roblox://` |
| LDPlayer 9 (เฉพาะมาโคร) | `ldplayer/PressE.record` นำเข้าในตัวบันทึกการกดของ LDPlayer (Operation Recorder) ใช้กดปุ่ม E ครั้งเดียวโดยไม่ขยับเมาส์ |

## ติดตั้ง

1. เปิด `chrome://extensions`
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้ (`RoomSpoofer`)
4. เปิดหน้าเกม Hunting Together RPG แผง RoomSpoof จะขึ้นที่มุมขวาล่าง

ถ้าแก้โค้ด ให้กดปุ่ม ↻ (Reload) ของ extension ใน `chrome://extensions` แล้วรีเฟรชหน้าเกม

ลากที่หัวแผงเพื่อย้ายตำแหน่งได้ ตำแหน่งและการตั้งค่าจะถูกจำไว้

### ตั้งค่า

- **เรียงห้องตาม**
  - *สมดุล* (ค่าเริ่มต้น): คะแนน = ping + 20ms × จำนวนคน (คนเพิ่ม 1 คน ≈ ping แย่ลง 20ms)
  - *Ping ต่ำสุดก่อน*: ถ้า ping เท่ากันค่อยดูคนน้อย
  - *คนน้อยสุดก่อน*: ถ้าคนเท่ากันค่อยดู ping
- **Ping สูงสุด / จำนวนคนสูงสุด**: ตัวกรอง (0 = ไม่จำกัด)
- **จำนวนหน้าที่สแกน**: หน้าละ 100 ห้อง เรียงจากคนน้อยไปมาก (1 หน้าก็พอสำหรับหาห้องคนน้อย)
- **คูลดาวน์ต่อห้อง**: นาที (0 = ปิด)

## ข้อควรรู้

- **ค่า Ping มาจาก Roblox API** เป็น ping เฉลี่ยของผู้เล่นที่อยู่ในห้องนั้น ไม่ใช่ ping จากเครื่องเราไปถึง server โดยตรง
  แต่ใช้เป็นตัวบอกคร่าวๆ ได้ว่าห้องไหนเล่นลื่น
- Roblox จำกัดการดึงรายชื่อห้องไว้ประมาณ **3 ครั้ง/นาที** ถ้าโดนจำกัด (HTTP 429) แผงจะนับถอยหลังแล้วลองใหม่เอง
- คูลดาวน์เก็บใน `chrome.storage.local` ใช้ร่วมกันทุกแท็บ และยังอยู่แม้ปิด Chrome
- ครั้งแรกที่เข้าห้อง Chrome อาจถามว่า “Open Roblox?” ให้กด Open (ติ๊ก Always allow ได้)

## ไฟล์

- `manifest.json` — ตั้งค่า extension (Manifest V3) ให้ทำงานเฉพาะ URL ของเกมนี้
- `content.js` — แผง UI, ดึงรายชื่อห้อง, จัดอันดับ, คูลดาวน์
- `launcher.js` — รันใน context ของหน้าเว็บเพื่อเรียก `Roblox.GameLauncher.joinGameInstance` (ถ้าไม่มีจะใช้ลิงก์ `roblox://` แทน)
- `background.js` — เปิดไอคอนบน toolbar เฉพาะหน้าเกมนี้ และใช้เป็นปุ่มซ่อน/แสดงแผง
- `icons/` — ไอคอน
