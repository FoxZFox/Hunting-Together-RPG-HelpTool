# Hunting Together RPG Help Tool

เครื่องมือช่วยเล่น Hunting Together RPG (Roblox) บน LDPlayer

| โฟลเดอร์ | ทำอะไร |
| --- | --- |
| [`BotLevel99/`](BotLevel99/README.md) | บอทปั้นคลาสให้ถึง Lv.99: ตีมอนตามแผนเลเวล, Auto Gear/Card, ย่อยของ, อัพ Stats ตามตาราง, ฟาร์มการ์ดบอสโลกพร้อมย้ายห้อง และหน้าควบคุมบนเบราว์เซอร์ |

บอทคุมเกมผ่าน adb ใน LDPlayer อย่างเดียว ไม่ขยับเมาส์หรือคีย์บอร์ดของ Windows วิธีติดตั้งและใช้งานอยู่ใน [BotLevel99/README.md](BotLevel99/README.md)
