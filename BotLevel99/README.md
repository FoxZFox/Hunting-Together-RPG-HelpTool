# BotLevel99: บอทปั้นเลเวลคลาสใน Hunting Together RPG (LDPlayer)

บอทจะดูเลเวลของคลาสที่เล่นอยู่ แล้วเปิด **Adventure Book > Card Book** เลือกการ์ดของมอนที่กำหนดไว้ในแผน และกด **Hunt this monster** ให้
จากนั้นเกมจะวิ่งไปตีและใช้สกิลเอง เมื่อเลเวลถึงช่วงถัดไปบอทจะเปลี่ยนไปตีมอนตัวใหม่ให้อัตโนมัติ

บอทสั่งงานผ่าน adb ข้างใน LDPlayer ทั้งหมด **ไม่ขยับเมาส์และไม่กดคีย์บอร์ดของ Windows** ระหว่างนั้นใช้คอมทำอย่างอื่นได้
กระเป๋าเปิดด้วยปุ่ม **B**, Adventure Book เปิดด้วยปุ่ม **N** และ Status & Skills เปิดด้วยปุ่ม **C** (ส่งเข้าคีย์บอร์ดของ LDPlayer โดยตรง) ถ้าปุ่มไม่ติดจะเปิดผ่านเมนูแทน บอทจำกระเป๋าได้จากไอคอนกระเป๋า คำว่า "Bag" ปุ่ม Auto Gear และปุ่ม X อย่างน้อย 2 อย่าง (บางทีไอคอนยังโหลดเป็นรูปโลก และเมาส์ของ Windows ที่ค้างอยู่บนปุ่ม X ก็ติดมาในภาพหน้าจอด้วย)

## บอททำอะไรบ้าง

| ทำอะไร | เมื่อไหร่ |
| --- | --- |
| กด Hunt this monster ตามแผนในไฟล์ `config.toml` | ตอนเริ่ม และทุกครั้งที่เลเวลเข้าช่วงใหม่ในแผน |
| กด Stop ที่การ์ดมอนใน Card Book แล้วปิดแล้วเปิด Auto ใหม่ (กด F 2 ครั้ง) ให้ตีทุกตัวแถวนั้น ไม่ใช่แค่ตัวที่ Hunt (กด F อย่างเดียวไม่พอ ตราบใดที่ยัง Hunt อยู่ Auto ก็ยังเล็งแค่ตัวนั้น) | หลังกด Hunt แล้วเดินถึงที่ฟาร์ม: บอทดูทุก 3 วินาทีจนแถบเป้าหมายด้านบนขึ้นชื่อมอนที่ Hunt และเลือดมันขยับ (กำลังตีจริง ไม่ใช่ยังเดินอยู่) รอได้นานสุด 3 นาที หลังกด Stop บอทเช็คว่าปุ่มกลับเป็น Hunt แล้ว ดาบมุมขวาล่างสีเขียว = Auto เปิด สีขาว = ปิด บอทเช็คสีดาบหลังกด F ทุกครั้ง (ปิดได้ด้วย `auto_all_after_hunt = false` หรือในแท็บตั้งค่า) |
| กด E ทุก 0.2 วินาที (5 ครั้งต่อวินาที) เพื่อเปิดกล่อง Hard Worker Box ที่อยู่ใกล้ตัว ตัวละครเดินผ่านกล่องในราว 1 วินาที กดทุก 1 วินาทีจึงพลาดบ่อย | ระหว่างรอเช็คจอรอบถัดไป เฉพาะตอนอยู่ที่ฟาร์ม คือเห็นแถบเลือดมอนด้านบนภายใน 1 นาทีที่ผ่านมา (กด Hunt ใหม่เมื่อไหร่ต้องเห็นแถบอีกรอบ เพราะทางเดินอาจผ่านเมือง) ในเมืองไม่มีแถบนี้ บอทจึงไม่กด E ใส่ NPC ไม่กดตอนเปิดหน้าต่างอื่นอยู่ กด 1 ครั้งใช้ adb ราว 0.05 วินาที (ตั้งได้ที่ `press_e_every_s` ใส่ทศนิยมได้ ต่ำสุด 0.1, 0 = ไม่กด) |
| กด Auto Gear แล้วตามด้วย Auto Card ในกระเป๋า | ทุกครั้งที่เลเวลอัพ และทุก 15 นาที |
| ย่อยของที่เหลือ: ปุ่มค้อน > Select All > Dismantle 2 ครั้ง > OK | ต่อจาก Auto Gear/Card ทุกครั้ง (ปิดได้ด้วย `dismantle = false`) |
| อัพ Stats ตามตารางของอาชีพนั้น แล้วกด Confirm Points | ตอนเริ่ม และทุกครั้งที่เลเวลอัพ (ต่อจาก Auto Gear) เฉพาะอาชีพที่มีตาราง |
| กด Hunt ใหม่ | เมื่อหลอด EXP ไม่ขยับ 3 นาที (เช่น ตาย หรือหลุดจากการตี) |
| เข้าเกมใหม่ | Roblox เด้งหรือปิดไป, ค้างครบ 3 รอบติดกัน, หรือเจอหน้าจอที่ไม่รู้จักนานเกิน 1 นาที |
| ปิดแล้วเปิด LDPlayer ใหม่ | LDPlayer ไม่ตอบ (adb ดึงภาพไม่ได้) หรือเข้าเกมใหม่ไม่สำเร็จ ติดกัน 3 รอบ ใช้เวลาประมาณ 1 นาทีครึ่งก็กลับเข้าเกมได้ ถ้าเปิดใหม่ 3 รอบแล้วยังไม่ได้ จะพัก 10 นาทีแล้วลองอีก |
| กด Reconnect | เจอปุ่ม Reconnect ของ Roblox บนจอ (ยังไม่เคยเจอหน้าจอนี้จริงตอนทดสอบ) |
| หยุดและส่งเสียงเตือน | เมื่อถึงเลเวล 99 (ปรับได้ที่ `stop_level`) |

สิ่งที่เกมทำเองอยู่แล้ว บอทจึงไม่ได้ยุ่ง:
- ลงแต้มสถิติของอาชีพที่ไม่มีตารางอัพ Stats ใช้ **Auto Upgrade Status** ในหน้า Status & Skills > Stats (อาชีพที่มีตาราง บอทปิดอันนี้แล้วลงแต้มเอง)
- อัพสกิล ใช้ **Auto Upgrade Skills** ในหน้า Skills
- ตีและใช้สกิลเอง ปุ่ม F จะขึ้น ON หลังกด Hunt
- ใช้ยาเอง ตามที่ตั้งไว้ข้างปุ่มยา (<70% / <20%)

ให้เปิด Auto Upgrade Skills ไว้ก่อนรันบอท (Auto Upgrade Status เปิดไว้ได้ ถ้าอาชีพนั้นมีตาราง บอทจะปิดให้เอง)

## วิธีใช้

1. เข้าเกมใน LDPlayer ให้ตัวละครอยู่หน้าเกมปกติ ไม่มีหน้าต่างอื่นเปิดค้าง
2. ดับเบิลคลิก `run.bat` เบราว์เซอร์จะเปิดหน้าควบคุมที่ http://127.0.0.1:8765 ให้เอง
   - **ครั้งแรก:** `run.bat` สร้าง Python venv ไว้ในโฟลเดอร์ `.venv` แล้วติดตั้ง library ตาม `requirements.txt` (opencv-python, numpy) ลงในนั้น ใช้เวลาประมาณครึ่งนาที library ของ Python ในเครื่องไม่ถูกแตะเลย
   - **ครั้งต่อไป:** มี `.venv` แล้วก็รันเลย ถ้า `requirements.txt` เปลี่ยนจะติดตั้งให้ใหม่เอง ถ้า venv เสีย ลบโฟลเดอร์ `.venv` แล้วเปิด `run.bat` ใหม่
3. เลือกโหมด **เก็บเลเวล** หรือ **ล่าบอส** แล้วกดปุ่มเริ่ม / หยุดบอท ที่มุมขวาบน
4. เลิกใช้แล้วให้ปิดหน้าต่างดำของ `run.bat` (ปิดแค่แท็บเบราว์เซอร์ บอทยังทำงานต่อ)

อย่าเปิด `run.bat` สองหน้าต่าง หรือเปิดคู่กับ `python bot.py run` เพราะบอทสองตัวจะแย่งกันกดเกม

### หน้าควบคุม

บอททำได้ทีละอย่าง เลือกที่ปุ่ม **เก็บเลเวล | ล่าบอส** มุมขวาบน แล้วกดปุ่มเริ่ม (เปลี่ยนโหมดได้ตอนบอทหยุดอยู่ โหมดที่เลือกจำไว้ใน `config.toml` ที่ `[bot] mode`) ส่วนที่ใช้ร่วมกันทั้งสองโหมด: บันทึก, ขั้นตอน, ตารางอัพ Stats, มอนทั้งหมด, ตั้งค่า

| ส่วน | ทำอะไร |
| --- | --- |
| เส้นทางสู่ Lv.99 (โหมดเก็บเลเวล) | ทุกช่วงในแผนการตี สีด้านบนคือธาตุของมอน หมุดบอกว่าตอนนี้อยู่ช่วงไหน แถบเขียวคือผ่านช่วงนั้นไปแล้วเท่าไหร่ |
| บอสที่จะล่า (โหมดล่าบอส) | บอสโลกทุกตัว กดที่บอสเพื่อเลือกหรือเลิกเลือก เลขแดงคือลำดับที่จะล่า หมุด "กำลังล่า" คือตัวที่บอทล่าอยู่ ติ๊กเขียวคือได้การ์ดแล้ว |
| ตอนนี้ | โหมดเก็บเลเวล: เลเวล, EXP, มอนที่กำลังตี, ตัวถัดไป โหมดล่าบอส: บอสที่กำลังล่า, ฆ่าไปกี่ตัว, เฉลี่ยกี่วินาทีต่อตัว, ย้ายห้องกี่ครั้ง, การ์ดที่ได้ |

| บันทึก | บอททำอะไรไปบ้าง แถบซ้ายสีเขียว = ไปตี, เหลือง = เลเวลอัพ/ฆ่าบอส/ได้การ์ด, ฟ้า = ใส่ของ/ย่อยของ/ย้ายห้อง, แดง = มีปัญหา |
| ขั้นตอน | ทุกขั้นตอนที่บอททำ (เปิดสมุด, เลือกแมพ, เลือกการ์ด, Leave, รอโหลด ฯลฯ) พร้อมเวลาที่ใช้ แถบส้มเกิน 10 วินาที แดงเกิน 20 วินาที ตารางข้างๆ สรุปว่าขั้นตอนไหนกินเวลารวมมากที่สุด ใช้ดูว่าบอทช้าตรงไหน เก็บลงไฟล์ `logs/steps.log` ด้วย |
| แผนการตี (โหมดเก็บเลเวล) | แก้ช่วงเลเวลกับมอน กดบันทึกแล้วบอทใช้แผนใหม่ทันที ไม่ต้องหยุดบอท |
| ตั้งค่าล่าบอส (โหมดล่าบอส) | เวลาย้ายห้อง, วิธีเลือกห้อง, ซูมกล้อง และรายการการ์ดที่ได้ระหว่างล่าบอส |

| Build | **คำนวณ Build อัตโนมัติ** (Lv.99, ตอนนี้ 6 อาชีพ: Samurai, Thief, Archer, Cleric, Merchant, Swordsman): ตั้ง ASPD และ Crit ขั้นต่ำ เลือกตีบอสหรือฟาร์ม กรอกออปของที่ใส่อยู่ได้ (ไม่กรอก = ไม่นับของ) ติ๊กการ์ดที่มี แล้วกดคำนวณ จะได้ Stats, ชุดเซ็ท, Extra และการ์ด 8 ใบที่ดาเมจต่อวินาทีสูงสุด เป็น **Full Build** (ทุกอย่าง) และถ้าติ๊กการ์ดไว้ ได้อีกแบบที่ใช้แค่การ์ดที่ติ๊ก Extra ของอาชีพที่ติ๊กว่า Lv.99 และชุดที่หาง่าย ปุ่ม "ใช้ Stats นี้กับบอท" แทนตารางอัพ Stats ของอาชีพนั้น (ถามก่อน) คิดจากสูตรของเกมใน `buildsim.py` (สูตร Ragnarok Online ที่วัดยืนยันจากตัว Lv.99 ทั้ง 6 ## ตั้งแผนการตี (`config.toml`)

```toml
plan = [
  { from = 42, to = 45, monster = "Wild Tiger" },
  { from = 46, to = 50, monster = "Saber Tiger" },
]
```

- `monster` ใช้ชื่อตามหน้า Monsters (ดูตารางข้างล่าง) ตัวพิมพ์เล็กหรือใหญ่ก็ได้
- บอทจะเลือกแถวแรกที่เลเวลตอนนั้นอยู่ในช่วง `from`–`to`
- ถ้าเลเวลตอนนั้นไม่ตรงกับแถวไหนเลย บอทจะไม่ทำอะไร ปล่อยให้ตีตัวเดิมต่อ
- แก้ไฟล์แล้วต้องปิดบอทแล้วเปิดใหม่ ค่าใหม่ถึงจะมีผล

แผนเริ่มต้นที่ใส่ไว้ จะตีมอนธรรมดาที่เลเวลไม่เกินตัวเรา
ถ้าตัวละครแข็งพอ ตีมอนที่สูงกว่าตัวเราหรือตี Leader จะได้ EXP ต่อเวลามากกว่า Leader ให้ EXP ต่อ HP ประมาณ 1.1–1.7 เท่าของมอนธรรมดาในแมพเดียวกัน แต่เกิดทีละตัว

ค่าอื่นในหมวด `[bot]`:

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `stop_level` | 99 | ถึงเลเวลนี้แล้วหยุด |
| `check_every_s` | 15 | เช็คหน้าจอทุกกี่วินาที |
| `stall_minutes` | 3 | EXP ไม่ขยับกี่นาทีถึงจะกด Hunt ใหม่ |
| `auto_gear_minutes` | 15 | กด Auto Gear/Card ทุกกี่นาที |
| `dismantle` | true | ย่อยของที่เหลือหลัง Auto Gear/Card |
| `unknown_timeout_s` | 60 | ค้างที่หน้าจอที่ไม่รู้จักนานเท่าไหร่ถึงจะเข้าเกมใหม่ |
| `restart_after_failures` | 3 | LDPlayer ไม่ตอบหรือเข้าเกมไม่ได้ติดกันกี่รอบ ถึงจะปิดแล้วเปิด LDPlayer ใหม่ |
| `join_url` | `roblox://placeId=117483759937632` | ลิงก์ที่ใช้เข้าเกมใหม่ |

## ตารางอัพ Stats (`[stats]` ใน `config.toml`)

แก้ได้ในแท็บ "ตารางอัพ Stats" ของหน้าควบคุม หรือแก้ในไฟล์เอง:

```toml
[stats]
Merchant = [
  { level = 30, STR = 36, AGI = 21 },
  { level = 40, STR = 48, AGI = 29 },
]
```

- ชื่ออาชีพต้องตรงกับที่เขียนในกระเป๋า (เช่น "Lv.31 Merchant") บอทอ่านชื่อนี้ตอนเปิดกระเป๋ากด Auto Gear
- แต่ละแถวคือค่า Stats ที่อยากได้เมื่อถึงเลเวลนั้น stat ที่ไม่ใส่จะไม่ถูกอัพ
- บอททำทีละแถวจากบนลงล่าง ในแถวเดียวกัน stat ที่ตามหลังเป้ามากที่สุดได้แต้มก่อน ทุก stat จึงไปถึงเป้าพร้อมกัน ถ้า stat ที่ต้องอัพต่อมีค่าแต้มแพงกว่าที่เหลือ จะเก็บแต้มไว้รอเลเวลหน้า
- อาชีพที่มีตาราง บอทจะปิด **Auto Upgrade Status** ของเกมให้เอง ไม่งั้นเกมจะเอาแต้มไปลงเองทุกครั้งที่เลเวลอัพ อาชีพที่ไม่มีตาราง บอทไม่แตะหน้า Stats เลย
- ก่อนกด Confirm Points บอทเช็คก่อนว่าแต้มที่ใช้ไปแล้วรวมกับแต้มที่เหลือ เท่ากับแต้มทั้งหมดของเลเวลนั้นพอดี (สูตร floor(Lv/5)+3 ต่อเลเวล Lv.99 ได้ 1,244 แต้ม) ถ้าไม่ตรง แปลว่าอ่านตัวเลขผิด บอทจะไม่อัพและเก็บภาพไว้ใน `logs/` เพราะแต้มที่ยืนยันไปแล้วเอาคืนไม่ได้ถ้าไม่ Reset Stats
- หลังกด + บอทเช็คอีกรอบว่าแต้มที่เหลือตรงกับที่คิดไว้ ถ้าไม่ตรงจะกด Clear แล้วไม่ยืนยัน

ตาราง Merchant ที่ใส่ไว้: STR ประมาณ 70% ของแต้ม, AGI 30%, ไม่ลง VIT
วัดจากในเกมตอน Lv.31: STR +1 ได้ ATK +1 (ใช้ 4–5 แต้ม), AGI +1 ได้ ASPD +0.27 (ใช้ 2 แต้ม) ทั้งคู่ได้ดาเมจประมาณ 0.2% ต่อแต้มเท่าๆ กัน
ตาราง Thief ที่ใส่ไว้ (ตัวละครถึง Lv.99 แล้ว จึงเป็นค่าสุดท้ายที่ 1,244 แต้มพอดี): STR 99, AGI 76, LUK 54, ไม่ลง VIT
AGI 76 คือจุดที่ ASPD ชน 190 (ตี 5.0 ครั้งต่อวินาที) ตอนวัดที่ Lv.90 โดยใส่การ์ด Fire Bat (AGI +5) กับ Rabbit King (AGI +3) อยู่ ถ้าเปลี่ยนการ์ดหรือของที่ให้ AGI/ASPD จุดนี้จะเลื่อน
STR เต็มก่อนเพราะได้ดาเมจต่อแต้มมากกว่า LUK ราวเท่าตัว แต้มที่เหลือจึงลง LUK (Crit ช่วยให้ Venom Dash พุ่งซ้ำ)
ตาราง Samurai ที่ใส่ไว้: ที่ Lv.99 ได้ STR 81, AGI 87, LUK 55, DEX 27, ไม่ลง VIT (แก้วันที่ 4 พ.ย. 2026 ตอน Lv.81 ดูเหตุผลด้านล่าง)

| เลเวล | STR | AGI | LUK | DEX |
|---|---|---|---|---|
| 60 | 50 | 50 | 28 | 11 |
| 70 | 50 | 70 | 28 | 14 |
| 80 | 50 | 84 | 31 | 25 |
| 85 | 50 | 87 | 45 | 27 |
| 90 | 58 | 87 | 53 | 27 |
| 95 | 70 | 87 | 53 | 27 |
| 99 | 81 | 87 | 55 | 27 |

วัดจากหน้า Stats ของ Samurai Lv.54 (วันที่ 4 พ.ย. 2026) โดยกด + ไว้ก่อน (ยังไม่ยืนยัน) แล้วดูตัวเลขสีเขียวที่เกมขึ้นให้ จากนั้นกด Clear
- STR +1 = ATK +1 (แต้มละ 6 ตอนนี้)
- AGI +1 = ASPD +0.15 ตอน ASPD 173 ตีได้ 50 / (200 − ASPD) ครั้งต่อวินาที AGI 1 แต้มจึงตีเร็วขึ้นราว 0.56% เทียบกับ STR 1 แต้มที่ได้ ATK เพิ่มแค่ 0.24% (แต้มละ 5)
- LUK +1 = Crit +0.33%, ATK +0.33 (แต้มละ 4) ตอนนั้น Crit 43% และ Crit DMG +64% (คริตแรง ×1.64)
- DEX +1 = ASPD +0.04, ATK +0.2, Cast Speed +0.78% (แต้มละ 2) ไม่ได้นับค่า Cast Speed ว่ามีผล

สกิลของ Samurai ใช้ ATK ทั้งหมด (Quick Draw 373% ตามความเร็ว ASPD, Blossom Dance 430%, Counter Stance 910%, Mirror Mind ATK Speed +15% / CRIT +15 / Crit DMG +15%, Lingering Edge บวก ATK ตาม AGI) คำนวณว่าความเร็วโจมตีคิดเป็น 3 ใน 4 ของดาเมจทั้งหมด แล้วเลือกลงแต้มทีละแต้มให้ได้ดาเมจเพิ่มมากที่สุดต่อแต้ม ผลคือ AGI 99 ก่อนเสมอ (ถึง AGI 99 ก็ยังไม่ชน ASPD 190) ส่วนที่เหลือ STR, LUK, DEX ได้ดาเมจต่อแต้มใกล้กัน ลองเปลี่ยนสมมติฐาน (สัดส่วนดาเมจที่ตามความเร็ว 60–90%, ATK จากของสวมใส่ที่โตขึ้นถึงเท่าตัวตอน Lv.99) ได้ AGI 99 เหมือนเดิมทุกครั้ง ที่เหลือต่างกันไม่กี่เปอร์เซ็นต์ เกมแนะนำ STR เป็น "Raise first" แต่ตัวเลขที่วัดได้บอกว่า AGI คุ้มกว่าเกือบเท่าตัว
VIT 15 ที่ Auto Upgrade ของเกมลงไว้เสียไป 32 แต้ม แต่ถ้าไม่ Reset ดาเมจตอน Lv.99 ต่ำกว่า build ที่ Reset แค่ราว 1% เลยไม่ต้อง Reset (ถ้า Reset ตารางนี้ก็ยังใช้ได้ จะเหลือแต้มว่างตอน Lv.99 ราว 34 แต้ม ใส่ LUK เพิ่มได้)
**ตอน Lv.81 (หยุด AGI ที่ 87):** ใส่ชุด SetGale 5/5 (ASPD +3) กับ Extra Killer Instinct (Attack Speed +10%) แล้ว หน้า Stats ขึ้น ASPD 189 (ตี 4.5 ครั้งต่อวินาที) ผู้เล่นเห็น 190 ตอน Lv.80 AGI 85 → 87 แล้ว ASPD ไม่ขยับเลย (ขึ้นไม่ถึง 0.25) เพราะยิ่งใกล้ 190 แต่ละแต้มยิ่งได้น้อย และพอถึง 190 แล้ว AGI ได้แค่ ATK +0.15 ต่อแต้มจาก Lingering Edge ตารางใหม่เลยหยุด AGI แล้วลง LUK ก่อน (Crit 78% + Mirror Mind CRIT +15 เต็ม 100% ราว LUK 53) ที่เหลือลง STR ถ้า ASPD ยังไม่ถึง 190 ตอนตี ใช้ Extra Blade Training (Attack Speed +10%) หรือการ์ด Whitefang (+8%) แทนการลง AGI จะถูกกว่ามาก


**หน้าต่าง Status & Skills เลื่อนซ้ายขวาได้:** วันที่ 4 พ.ย. 2026 หน้าต่างอยู่ซ้ายกว่าวันก่อน 66 px (แถบบนของ Roblox มีไอคอนน้อยลงหนึ่งอัน) ทุกครั้งที่เปิดหน้า Stats บอทหาคำว่า "STR" ก่อน แล้วเลื่อนตำแหน่งทุกปุ่มตามที่หน้าต่างอยู่จริง ถ้าหาไม่เจอจะไม่กดอะไรเลย

ถึงเลเวลที่ตั้งหยุดไว้ (`stop_level`) บอทจะลงแต้มของเลเวลสุดท้ายก่อนแล้วค่อยหยุด ตัวละครที่ Lv.99 อยู่แล้วกดเริ่มบอทครั้งเดียวก็ลงแต้มให้ได้ หรือกด "อัพ Stats ตอนนี้" ในแท็บตารางอัพ Stats

ตีธรรมดา, Coin Smash และ Whirl Axe เร็วขึ้นตาม ASPD แต่ Merchant ถือขวานจึงไม่มีทางถึง ASPD 190 (AGI 99 น่าจะได้ราว 149) ส่วน Auto Upgrade ของเกมลง VIT เกือบเท่า STR ได้ดาเมจน้อยกว่าตารางนี้ประมาณ 12–17%

## ฟาร์มการ์ดบอสโลก (`[boss]` ใน `config.toml`)

บอสโลกเกิดใหม่ทุก 10 นาทีต่อห้อง บอทจึงย้ายห้องไปหาห้องที่บอสยังอยู่แทนการรอ

1. เปิดสมุดการ์ด แล้วกด Hunt this monster ที่การ์ดบอส ตัวละครเดินเข้าห้องบอสเอง
2. ดูจอทุกประมาณ 1 วินาที
   - **เห็นป้าย "Boss" ที่แถบเลือดด้านบน:** บอสอยู่ ตีจนตาย แล้วรอดูหน้าต่าง "Obtained!" อีก `after_kill_s` วินาที (ค่าเริ่มต้น 2) ถ้าชื่อการ์ดตรงกับบอสก็นับว่าได้การ์ดบอสแล้ว
   - **ตอนเปิดการ์ดบอสเพื่อกด Hunt:** บอทอ่านช่อง "Owned" ของการ์ดด้วย ถ้ามีการ์ดแล้ว (การ์ดบอสมีได้ใบเดียว) ก็ไปบอสตัวถัดไปเลย วิธีนี้ยังรู้ได้แม้หน้าต่าง Obtained! จะขึ้นหลังบอทย้ายห้องไปแล้ว
   - **เห็นป้าย "Respawns in M:SS":** บอสตายอยู่ ย้ายห้อง (หรือรอ ถ้าตั้ง `wait_respawn_s` ไว้แล้วเวลาเหลือไม่เกินนั้น)
   - **กด Hunt จากหน้าห้องแล้ว `appear_s` วินาที (ค่าเริ่มต้น 6) ยังไม่เห็นแถบเลือด:** ย้ายห้อง ถ้าตัวละครยืนกลางห้องแล้วกล้องหันไปทางประตู ป้ายนับถอยหลังจะอยู่นอกจอ แต่ผลก็เหมือนกันคือบอสไม่อยู่
3. ย้ายห้อง: กดโลโก้ Roblox > Leave > Leave ให้เกมเซฟก่อน (ถ้ากดไม่ได้จะปิด Roblox แทน) แล้วเข้าห้องที่เลือกผ่านลิงก์ `roblox://placeId=…&gameInstanceId=…` พอเกมโหลดเสร็จจะมีปุ่ม Skip ขึ้นทับมุมกล้องตอนเปิดเกม บอทเช็คจอทุก 1 วินาที เห็นปุ่มแล้วกดทันที (รู้ว่าเข้าเกมแล้ว และข้ามการหมุนกล้อง) จากนั้นกดปุ่ม O ของ Roblox `zoom_out_clicks` ครั้ง (ค่าเริ่มต้น 10) เพื่อซูมกล้องออก ส่งผ่านคีย์บอร์ดของ LDPlayer เหมือนปุ่ม B/N จึงใช้ได้แม้ไม่ได้คลิกหน้าต่าง LDPlayer (ล้อเมาส์ใช้ไม่ได้ถ้าหน้าต่างไม่ได้โฟกัส) ป้ายเวลาเกิดบอสจะอยู่ในจอทุกครั้ง

**ตามเวลาเกิดบอส (`follow_timers`):** ทุกห้องที่บอทเห็นป้าย "Respawns in" หรือฆ่าบอสเอง (บอสเกิดใหม่ 10 นาทีหลังตาย) บอทจะจำว่าบอสห้องนั้นเกิดตอนไหน ตอนย้ายห้อง ถ้ามีห้องที่บอสจะเกิดพอดีตอนเราไปถึง (ต้องไปถึงก่อนบอสเกิด ก่อนได้ไม่เกิน 15 วินาที เพราะห้องที่มีคนเฝ้าบอส บอสตายภายใน 3 วินาทีหลังเกิด) บอทจะเข้าห้องนั้นก่อน แล้วรอในห้องได้นานสุด `timed_wait_s` วินาที เวลาย้ายห้องจริง (ตั้งแต่กด Leave จนเริ่มดูห้องบอสในห้องใหม่) บอทจับเวลาเองทุกครั้งแล้วเอามาเฉลี่ย ใช้ได้เฉพาะห้องที่บอทเลือกเข้าเอง (รู้รหัสห้อง) ความจำนี้หายเมื่อปิดหน้าควบคุม

**การเลือกห้อง (`server_pick`):** บอทดึงรายชื่อห้องจาก API ของ Roblox (ไม่ต้องล็อกอิน แบบเดียวกับ RoomSpoof) แล้วเลือกจากห้องที่ยังไม่ได้เข้าภายใน `server_cooldown_min` นาที (ค่าเริ่มต้น 12 นาที บอสเกิดใหม่ทุก 10 นาที พอห้องหมดคูลดาวน์ บอสก็น่าจะเกิดแล้ว) และมีคนตั้งแต่ `server_min_players` คน (ค่าเริ่มต้น 6)
- **"fewest":** เรียงห้องจากคนน้อยไปมาก แล้วสุ่มจากอันดับ `server_skip` (ค่าเริ่มต้น `[0, 9]` คือ 10 ห้องที่คนน้อยที่สุด) เป็นค่าเริ่มต้น
- **"random":** สุ่ม แบบ Quick Join ของ Roblox
- **"most":** ห้องคนเยอะที่สุด

**ทำไมต้อง 6 คนขึ้นไป (`server_min_players`):** ผู้ใช้ลองย้ายห้องเองแล้วพบว่าห้อง 2–5 คนแทบทุกห้องมีคนเฝ้าบอส บางห้องใช้ Exploit ตีบอสตลอด บอสจึงตายอยู่เกือบตลอด ส่วนห้อง 6 คนขึ้นไปส่วนใหญ่เป็นคนเปิดบอทเก็บเลเวล ไม่มีคนเฝ้าบอส และยังไม่เจอคนใช้ Exploit เลย ตั้ง 0 = ไม่จำกัด ถ้าห้องที่ถึงขั้นต่ำติดคูลดาวน์หมด บอทจะเข้าห้องที่คนเยอะที่สุดในที่เหลือแทน (บันทึกจะบอก)

รายชื่อห้องที่ Roblox ส่งมาเรียงจากคนน้อยไปมาก หน้าละ 100 ห้อง (วันที่ 4 พ.ย. 2026: หน้าแรก 2–4 คน, หน้าสอง 4–7 คน, หน้าสาม 7–10 คน ห้องละไม่เกิน 13 คน) บอทอ่าน 2 หน้าก่อน แล้วอ่านหน้าถัดไปทีละหน้า (สูงสุด 6 หน้า) จนมีห้องที่เข้าได้ (ถึงขั้นต่ำและไม่ติดคูลดาวน์) อย่างน้อย 30 ห้อง Roblox ให้ขอรายชื่อได้แค่ประมาณ 3 ครั้งต่อนาที บอทจึงใช้รายชื่อเดิมต่อ 22.5 วินาทีต่อหน้าที่อ่าน (2 หน้า = 45 วินาที, 3 หน้า = 67 วินาที) ถ้า Roblox ไม่ยอมส่งรายชื่อ (429) บอทใช้รายชื่อเดิมที่อายุไม่เกิน 5 นาทีต่อ ถ้าเก่ากว่านั้นจะเข้าห้องสุ่มแทน

ทดสอบแล้วว่าเข้าห้องที่เลือกได้จริงบน LDPlayer: เลือกห้องที่มี 2 คน เข้าไปแล้วรายชื่อผู้เล่นในเมนู Roblox มี 3 คน (รวมเรา)

ห้องที่เข้าใหม่จะเกิดที่ที่ออกมาล่าสุด ถ้าเคยถึงห้องบอสแล้วก็จะเกิดหน้าห้องบอส รอบแรกของการเริ่มฟาร์มบอทยังไม่รู้ว่าตัวละครอยู่ที่ไหน จึงรอได้นานสุด 90 วินาทีหนึ่งครั้ง หลังจากนั้นถือว่าอยู่หน้าห้องแล้วใช้ `appear_s` ถ้าไม่เจอบอส 5 ครั้งติดกัน บอทจะเผื่อเวลาเดินไกลอีกรอบ เผื่อตัวละครไม่ได้อยู่หน้าห้องแล้ว

### หลบท่าบอส (`data/bosses.json`)

บอสบางตัวยืนตี Auto เฉยๆ ไม่ไหว ก่อนออกท่าบอสจะขึ้นตัวหนังสือสีแดงใต้แถบเลือด "Volcano Turtle King uses Magma Bite — get out of the red ground!" บอทอ่านบรรทัดนี้ (อ่านเฉพาะพิกเซลสีแดง เพราะพื้นหลังรก) แล้วกดปุ่มตามตารางในไฟล์ `data/bosses.json` ของท่านั้น นับเวลาจากตอนที่ภาพหน้าจอเห็นป้ายครั้งแรก

| ท่าของ Volcano Turtle King | บอททำอะไร | ดาเมจใหญ่ลงหลังป้ายขึ้น |
|---|---|---|
| Magma Bite, Lava Rain | กด Q (กลิ้ง) 2 ครั้ง ที่ +0.9 วิ | +1.7 – 2.1 วิ |
| Earthquake Stomp | กด Q 2 ครั้ง ที่ +1.0 วิ | +1.7 – 2.15 วิ |
| Flame Breath | กด W ค้าง 0.8 วิ ทันที (เดินเข้าไปอยู่ใต้บอส) | +1.1 – 1.6 วิ |
| Shell Fortress (ตอนบอสคลั่ง) | กด Q 2 ครั้ง ที่ +2.2 วิ ให้ทันดาเมจแรก (ดาเมจตอนหมุนต่อจากนั้นเบา) | +2.84 วิ |

- เวลาทั้งหมดวัดจากคลิปที่บันทึกตอนผู้เล่นตีเอง (อ่านเลือดทุกเฟรม) ทดสอบโดยเล่นคลิปนั้นผ่านโค้ดดูบอสตัวจริง: บอทอ่านป้ายเจอครบทั้ง 15 ครั้ง ช้าสุด 0.4 วิหลังป้ายขึ้น และกดทุกปุ่มก่อนดาเมจลง
- บอสที่มีในตารางนี้ บอทเช็คจอถี่ที่สุดเท่าที่ดึงภาพได้ (ป้ายอ่านออกแค่ 0.8 – 1.9 วิ) หลังเช็คครบ 20 รอบแรกบันทึกจะบอกว่าเช็คจอใช้เวลาเฉลี่ยกี่วินาทีต่อรอบ ควรต่ำกว่า 0.4 วิ
- แก้เวลาในไฟล์ได้ตอนบอทรันอยู่ บอทอ่านไฟล์ใหม่ทุกครั้งที่เริ่มดูบอส แต่ละท่ามี `steps` เป็นรายการ: `{"key": "Q", "at": 0.9, "times": 2}` = กดปุ่ม, `{"hold": "W", "at": 0, "for": 0.8}` = กดค้าง ปุ่มที่ใช้ได้: Q W E A S D F
- ทิศ W คือทิศที่กล้องหันไป ยังไม่ได้ลองกับบอสจริงว่าพาไปอยู่ใต้บอสได้หรือไม่

### ตายระหว่างตีบอส

ตอนตัวละครตาย ป้าย Boss บนแถบเลือดจะหายไปเหมือนตอนบอสตาย บอทจึงดูหน้าต่าง "You Died" ก่อนทุกครั้ง ถ้าเห็นจะกด **Respawn in town (free)** แล้วกด Hunt บอสตัวเดิมในห้องเดิมอีกรอบ (บอสยังอยู่) ถ้าตายครบ 5 ครั้งในห้องเดียวจะย้ายห้อง ส่วนปุ่มเขียว **Respawn here • 9 Robux** ที่อยู่เหนือปุ่มนั้นบอทไม่กดเด็ดขาด บอทกดเฉพาะบรรทัดที่อ่านได้ว่า "town" และ "free" (และไม่มีคำว่า Robux) เท่านั้น ไม่ได้กดตามตำแหน่งตายตัว จำนวนครั้งที่ตายแสดงที่ช่อง "ฆ่าบอส" ของหน้าควบคุม

## ข้อควรรู้

- **เข้าเกมใหม่แล้ว EXP บางส่วนหาย:** ตอนทดสอบ EXP ถอยจาก 46% เหลือ 27.5% ของเลเวล น่าจะเพราะเกมยังไม่ได้เซฟตอนปิดแอปแบบบังคับ บอทจึงเข้าเกมใหม่เฉพาะตอนที่จำเป็นเท่านั้น
- **ระหว่างบอทรันอย่ากดเกมเอง:** บอทอาจกดเมนูทับกับที่คุณกด ถ้าจะเล่นเองให้หยุดบอทก่อน
- **เมาส์ที่ชี้อยู่บนหน้าต่าง LDPlayer จะติดไปในภาพที่บอทเห็น:** บอทใช้จุดสังเกตหลายจุดต่อหน้าจอเพื่อไม่ให้หลงเพราะเมาส์บัง แต่จะดีที่สุดถ้าเอาเมาส์ออกจากหน้าต่าง LDPlayer ระหว่างบอททำงาน
- **LDPlayer ค้างทั้งที่หน้าต่างยังเปิดอยู่:** เคยเกิดตอนรันยาว Roblox หลุดแล้ว adb ดึงภาพไม่ได้อีกเลย บอทจึงเช็คทุกรอบว่า Android ใน LDPlayer ยังตอบไหม ถ้าไม่ตอบติดกันจะปิดแล้วเปิด LDPlayer ใหม่ให้เอง
- **ปุ่ม Hunt กลายเป็น Stop:** ถ้ามอนตัวนั้นกำลังถูกตีอยู่ ปุ่ม Hunt this monster จะเปลี่ยนเป็น Stop บอทเห็นแล้วจะไม่กด เพื่อไม่ให้หยุดการตีเอง
- **ย่อยของแทนการขาย:** บอทกด Auto Gear ก่อนทุกครั้ง ของดีจะถูกใส่ก่อนแล้วค่อยย่อยที่เหลือ ของที่ใส่อยู่ไม่ถูกย่อย ปุ่ม Select All ของเกมเลือกเฉพาะ Tier I–IV (ปุ่มจะเปลี่ยนชื่อเป็น "Tier I-IV" หลังกด) บอทกดปุ่มนี้แค่ครั้งเดียว และจะไม่กดเลยถ้าปุ่มไม่ได้เขียนว่า Select All ส่วน Sell Junk และ Sell Many บอทไม่กด
- **กดย่อยต้องเร็ว:** ปุ่ม Dismantle ต้องกด 2 ครั้งติดกันภายในประมาณ 1 วินาที ถ้าช้ากว่านั้นปุ่ม "Confirm dismantle?" จะกลับเป็น Dismantle และไม่มีอะไรถูกย่อย
- **ยาต้องเติมเอง:** บอทไม่ซื้อยาให้
- **ตัวละครตายตอนเก็บเลเวล:** ยังไม่เคยทดสอบ ถ้าตายแล้ว EXP ไม่ขยับ บอทจะกด Hunt ใหม่หลัง 3 นาที ถ้ายังค้างจะเข้าเกมใหม่ (โหมดล่าบอสจัดการหน้าต่าง You Died เองแล้ว ดูหัวข้อ "ตายระหว่างตีบอส")
- **ปุ่มที่บอทไม่กดเด็ดขาด:** Reset Stats, Reset Skills, Unequip All, Sell Junk, Sell Many, Respawn here • 9 Robux
- ประวัติการทำงานอยู่ที่ `logs/bot.log` ถ้าบอทเจอปัญหาจะเก็บภาพหน้าจอไว้ในโฟลเดอร์ `logs/` ด้วย
